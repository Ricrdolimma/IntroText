## Keyboard shortcuts
Shortcuts I frequently use: 
- command-C (copy)
- command-V (paste)
- command-Z (undo)
- command-X (cut and copy)
- command-F (find)
- command-T (open new tab)
- command-W (close the front window)
- command-shift-3 (screenshot)
- command-shift-4 (screenshot of a selected portion)
- Shift + Left arrow (select characters)

Shortcuts I would like to start using: 
- command-A (select all)
- option-Command-Esc (force an app to quit)
- command-D (duplicate selected file
